## Customer Behavior Data Analyst Portfolio Project
### Data Analytics Project: Cleaning, EDA, SQL Analysis & Power BI Dashboard

This repository showcases an end-to-end data analytics project, covering everything from initial data cleaning to advanced SQL analysis and interactive dashboard creation. 

The core datasets and project guidelines used in this analysis were sourced from the repository by [amlanmohanty1](https://github.com/amlanmohanty1). This project serves as an independent extension and execution of those materials to demonstrate practical data engineering and business intelligence capabilities. 

### 🛠️ Tech Stack & Tools

* **Data Cleaning & EDA:** Python (Jupyter Notebook, Pandas, NumPy)
* **Data Analysis & Querying:** PostgreSQL
* **Data Visualization:** Power BI

### 1. Data Cleaning & Exploratory Data Analysis (EDA)

Using **Jupyter Notebook**, the raw datasets were thoroughly audited and cleaned to ensure high data quality.

* Standardized text fields and formatted date columns for database compatibility.
* Conducted initial EDA using Pandas to understand distributions, outliers, and correlations.
