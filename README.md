## Customer Behavior Data Analyst Portfolio Project
### Data Analytics Project: Cleaning, EDA, SQL Analysis & Power BI Dashboard

This repository showcases an end-to-end data analytics project, covering everything from initial data cleaning to advanced SQL analysis and interactive dashboard creation. 

The core datasets and project guidelines used in this analysis were sourced from the repository by [amlanmohanty1](https://github.com/amlanmohanty1). This project serves as an independent extension and execution of those materials to demonstrate practical data engineering and business intelligence capabilities. 

### 🛠️ Tech Stack & Tools

* **Data Cleaning & EDA:** Python (Jupyter Notebook, Pandas, NumPy)
* **Data Analysis & Querying:** PostgreSQL
* **Data Visualization:** Power BI

### 🚀 Project Workflow & Activities

### 1. Data Cleaning & Exploratory Data Analysis (EDA)

Using **Jupyter Notebook**, the raw datasets were thoroughly audited and cleaned to ensure high data quality. 

* Handled missing values, duplicates, and erroneous data types.
* Standardized text fields and formatted date columns for database compatibility.
* Conducted initial EDA using Pandas to understand distributions, outliers, and correlations.

### 2. Relational Database Modeling & SQL Analysis

After structuring the cleaned data, it was migrated into a local **PostgreSQL** instance. 

* Designed the database schema and defined appropriate primary and foreign keys.
* Wrote complex SQL queries involving multi-table joins, subqueries, CTEs, and window functions to extract actionable business insights.
* *Key business metrics analyzed included:* [Insert 1-2 examples, e.g., monthly sales trends, customer retention, top-performing categories].

### 3. Power BI Visualization

To bring the data to life, a dynamic, interactive **Power BI Dashboard** was engineered. 

* Modeled the data relationships directly within Power BI.
* Developed custom DAX measures to calculate critical KPIs.
* Designed intuitive visuals focused on user experience, helping stakeholders quickly spot trends and make data-driven decisions.

### 📊 Key Insights Discovered

* **Insight 1:** Learned to import and use SQL databases in a sequence with python with the possibility to create automated report and dashboards.
* **Insight 2:** I found that dashboards really should answer stakeholder's or sponsor's concerns. It would be preferred to have a simple but actionable dashboard.
* **Insight 3:** More practice to enable automations soon.
